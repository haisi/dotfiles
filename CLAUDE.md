# Dotfiles: managed by chezmoi

All dotfiles in `$HOME` (`.zshenv`, `.config/zsh/*`, etc.) are generated by
chezmoi from this source repo at `~/.local/share/chezmoi`. The chezmoi
binary lives at `~/bin/chezmoi` and is on `PATH`.

## Golden rule

**Never edit a dotfile in `$HOME` directly** (e.g. `~/.zshenv`,
`~/.config/zsh/fzf.zsh`). Those are chezmoi-generated targets — the next
`chezmoi apply` will silently overwrite any direct edit. Always edit the
source file in this repo instead.

## Workflow for any dotfile change

1. Find the source file for a target path:
   `chezmoi source-path <target-path>` (e.g. `chezmoi source-path ~/.zshenv`)
   or browse `chezmoi managed` for the full list.
2. Edit the source file here (in `~/.local/share/chezmoi`).
3. Apply it: `chezmoi apply -v` (shows a diff of what changed).
4. Verify the change actually works (e.g. `zsh -c 'source ~/.zshenv; ...'`).
5. Commit inside the source repo: `chezmoi git -- add <file>` then
   `chezmoi git -- commit -m "..."`.

## Naming convention

chezmoi maps source file names to target paths:
- `dot_foo` → `~/.foo`
- `private_dot_config/zsh/bar.zsh` → `~/.config/zsh/bar.zsh` (private_ = 0600 perms)
- Plain names with no dot (e.g. `CLAUDE.md`) map to `~/CLAUDE.md` unchanged.

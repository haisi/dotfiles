= dotfiles

Managed with https://chezmoi.io[chezmoi]. Package/tool installation is
declarative via https://www.ansible.com[Ansible] — see `dot_bootstrap/setup.yml`
for the full list of packages, repos, and tools. See also `CLAUDE.md` for the
edit/apply/commit workflow.

Inspired by https://github.com/logandonley/dotfiles.

== New machine setup

Minimal manual prerequisites (curl/git/chezmoi don't exist yet, so they can't
be installed declaratively):

[source,shell]
----
sudo apt-get update && sudo apt-get upgrade -y
sudo apt-get install -y curl git
sh -c "$(curl -fsLS https://get.chezmoi.io)" -- init --apply haisi
----

That last command clones this repo, applies all dotfiles, and — via
`run_once_install_ansible.sh` — installs Ansible and runs
`dot_bootstrap/setup.yml`, which handles everything else: zsh (+ setting it
as the login shell), fzf, bat, eza, fd-find, ripgrep, starship, lf, chafa,
ghostty, the GitHub CLI, zoxide, and the JetBrainsMono Nerd Font. It will
prompt for your sudo password once (`--ask-become-pass`).

== Changing installed tools

Edit `dot_bootstrap/setup.yml` and run `chezmoi apply`. The
`run_onchange_bootstrap.sh.tmpl` script re-runs the playbook automatically
whenever that file's content changes.
